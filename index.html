执行摘要

本页对比客户拓亚（org 31558）在 2026.05 全月（上期）与 2026.10 全月（本期）的客服健康指标（全平台汇总，共 47 项）。两期均为完整 31 天（逐日探针确认 10-31 有数据），等长窗口、直接比累计原值，不做日均折算。总体呈「机器人全面接管售前接待、人工大幅收缩；单量下滑但客单价、转化率、响应时效与弃单率同步改善」的格局——这是一次承接结构调整带来的效率提升，而不是单纯的服务退坡。 量降价升，客单价是金额的支点：订单数 81,477 → 62,797（-22.9%）；订单金额 ¥607.5万 → ¥645.5万（+6.3%）；单均金额 ¥74.6 → ¥102.8（+37.9%）——单量掉了 22.9%，靠客单价抬 37.9% 把金额顶成正增长。非 COD 订单占比 24.51% → 23.63%，付款率 88.25% → 86.18%（-2.07pp）；非乐聊接待占比 2.41% → 2.30%，接待入口基本全部在乐聊内。 最显著的结构变化：机器人从试水变成主力：接待买家 9,152 → 3,370（-63.2%），接待覆盖率 11.23% → 5.37%；但结构彻底换了——人工接待 9,124 → 1,798（-80.3%），机器人接待 116 → 2,331（20.1 倍），机器人占比 1.27% → 69.17%（+67.90pp）；机器人承接的下单金额占接待后下单金额的比例由 2.3% 跃升到 82.9%。效率端同步改善：接待转化率 6.28% → 11.07%（+4.79pp）（人工 6.18% → 8.34%、机器人 15.52% → 13.64%）——接待量少了一半多，转化率反而接近翻倍，说明被过滤掉的主要是低意向流量。 响应时效是本期改善最扎实的一项：人工平均响应 1h23m → 0h26m（-57min / -68.4%），1 分钟内响应率 28.14% → 47.84%（+19.70pp）、3 分钟内 39.76% → 65.29%（+25.53pp）、60 分钟内被人工接待率 59.47% → 70.31%（+10.84pp）。唯一反向的是买家咨询平均等待接待 2h18m → 2h29m（+11min / +7.7%）——排队变长，与在接人工账号从 4 个减到 3 个一致。 弃单端大幅改善，但跟单助手出现两个口子：最终弃单率 27.03% → 18.38%（-8.66pp），弃单数 22,026 → 11,539 单、金额 ¥200.1万 → ¥167.2万；确认订单后发起的弃单率 34.29% → 18.87%（-15.42pp），几乎腰斩。物流呵护覆盖率则从 66.77% 降到 52.76%（-14.01pp），未呵护订单 12,301 → 14,864 张（未呵护弃单率 23.63%，是呵护后 14.60% 的 1.6 倍）；催付后付款率 26.35% → 23.94%（-2.41pp）。挽回端则在改善：弃单沟通率 26.19% → 28.95%（+2.76pp），沟通后挽回率 16.52% → 20.45%（+3.93pp），其中人工 19.99% → 29.70% 提升最明显。

结论与建议

主线是「机器人接住了流量、人工缩小了战线圈」。人工接待 9,124 → 1,798（-80.3%）、机器人接待 116 → 2,331，机器人占比 69.17%；换来的是接待转化率 6.28% → 11.07%、人工响应 1h23m → 0h26m、最终弃单率 27.03% → 18.38%、弃单金额 ¥200.1万 → ¥167.2万。订单数虽然 （-22.9%），但金额 （+6.3%）、单均 ¥74.6 → ¥102.8——这笔结构账是划算的：少掉的是低效接待与低客单订单，留下的是更高转化与更短响应。 代价与风险有三处，都不在「效率」上，而在「覆盖」上。一是接待覆盖收得太快：接待覆盖率 11.23% → 5.37%，买家咨询平均等待接待 2h18m → 2h29m、60 分钟内被人工接待率仅 70.31%，人工坐席只剩 3 个在接（5 月为 4 个）；二是物流呵护覆盖率 66.77% → 52.76%，未呵护 14,864 张正在裸奔，弃单率 23.63% 是呵护后的 1.6 倍；三是机器人挽回质量仍偏弱：机器人沟通 2,805 单、挽回率 16.97%，低于未沟通订单的自然挽回率 20.02%，也远低于人工的 29.70%——机器人触达在「量」上铺开了，在「质」上还没过关。 建议下一周期：① 把物流呵护覆盖率拉回 65% 以上——当前 52.76%、未呵护 14,864 张，按未呵护与呵护后弃单率的 9.0pp 差距估算，覆盖率每回升 10pp（约 3,146 张呵护量）约可少弃 284 单 / 月，这是投入产出比最高的一项；② 机器人沟通按「原因 × 客单」分层，别一把抓——「Failed Delivery」机器人沟通率 66.75% 但挽回率仅 2.82%，而「Unpaid Order」1,131 张几乎零触达，这两类应直接派人工；机器人只保留「Others / change of mind」这类标准首触；③ 补承接但不急着加人——人工响应已从 1h23m 压到 0h26m，说明现有人力效率足够；把排队超 30 分钟的会话自动升级、按账号错峰（温惠燕响应 3h24m → 0h36m 的经验可复制），把 60 分钟内被人工接待率从 70.31% 拉到 80% 以上。

  • 口径核对：5 月与 10 月分别按整月独立取数，订单数 81,477 / 62,797、订单金额 ¥6,074,663 / ¥6,455,025，与看板一致；弃单原因卡按「平台 × 站点 × 类型 × 原因」分行，同一原因跨站点会重复出现，本期原因合计 14,281 单高于「发起可挽回弃单数」13,073 单（差 9.2%），故 TOP12 仅按原因单列排序，不与总弃单量做加总对比。
  • 跟单助手三项能力在本客户均已启用：物流呵护本期执行 16,598 单（占确认订单 52.76%）、催付执行 1,809 单（占应催付 86.93%）、弃单沟通由机器人承担 74.1%（2,805 / 3,785 单）；与 5 月相比的主要变化在于呵护覆盖率（66.77% → 52.76%，下降 14.01pp）、催付后付款率（26.35% → 23.94%）与机器人沟通后挽回率（12.96% → 16.97%），相关缺口与改善已在摘要与结论中分列说明。

  • 「弃单挽回率」「最终弃单率」的分母为该窗口订单总数（按周期去重，未因按弃单类型分行而重复计入）。
